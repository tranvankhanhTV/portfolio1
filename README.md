# Portfolio — Trần Văn Khánh

Static, single-page portfolio site.

## Main files

- `index.html` — page content and metadata
- `css/style.css` — layout, responsive rules, and visual effects
- `js/main.js` — interactions and animations
- `anh 4 ....png` — profile image
- `a011.pdf` — CV downloaded by the page's CV buttons

## Run locally

Open `index.html` in a browser. The page uses external Google Fonts, Font Awesome, Three.js, Google Maps, and live project links, so those features require an internet connection.

The site is static and has no build step or package dependencies.
